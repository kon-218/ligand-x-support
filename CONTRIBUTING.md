# Contributing

Thank you for helping improve Ligand-X. This repository accepts issue reports, Discussions, and changes
to the support documentation and forms; it does not contain the private Core or Pro implementation.

## High-quality reports

- Use the most specific issue form.
- Report one problem or proposal per issue.
- State versions and platform details precisely.
- Provide deterministic reproduction steps and the smallest non-confidential example available.
- Paste relevant text logs in code blocks instead of screenshots when possible.
- Explain expected and observed behavior separately.
- Search for duplicates and add useful evidence to an existing issue when one exists.
- Follow [PRIVACY.md](PRIVACY.md) before uploading any artifact.

Maintainers may edit titles, labels, or formatting; request additional information; move questions to a
Discussion; link duplicates; or close reports that cannot be acted on safely.

## Pull requests

Pull requests are welcome for corrections to the public support material. Keep changes focused and do
not add implementation code, generated files, private-source references, customer data, or AI
attribution. By contributing, you confirm you have the right to submit the material under the
repository's existing terms.
